## $i$个测站，$j$个卫星，$k$个历元

|       |       观测方程总数(线性无关的观测值)        |
| :---: | :---------------------------: |
| 站间单差  |     $(i-1)\cdot j\cdot k$     |
| 星间单差  |     $i\cdot (j-1)\cdot k$     |
| 历元间单差 |     $i\cdot j\cdot (k-1)$     |
|  双差   |   $(i-1)\cdot (j-1)\cdot k$   |
|  三差   | $(i-1)\cdot (j-1)\cdot (k-1)$ |
